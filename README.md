# 小学校の校務PCで使えるソフト

https://a071013n-sudo.github.io/my-tool/

## 更新するとき

**`tools.js` だけを編集してください。** 他のファイルは触る必要がありません。

GitHubの画面から直接編集できます（スマホからでも可）。

1. GitHubでこのリポジトリを開く
2. `tools.js` をクリック → 鉛筆アイコン（Edit）
3. `window.TOOLS` の配列にツールを1つ足す
4. 下の「Commit changes」を押す

保存すると数分後に、サイトとチラシPDFの両方が更新されます。

## ツール1件の書き方

```js
{
  id: "my-tool",                    // 必須。半角英数字。他と重ならないように
  name: "ツールの名前",              // 必須
  description: "詳しい説明",         // 必須（summary でも可）

  // ここから下は省略できます
  icon: "🌱",
  category: "校務・事務",            // CATEGORY_COLOR にある種類から選ぶ
  env: "ブラウザのみ",
  tags: ["Python", "Excel"],
  summary: "一覧カード用の短い説明",
  updated: "2026-08",               // YYYY-MM 形式
  download: "https://github.com/.../releases",
  repo: "https://github.com/...",

  // 先生方の判断材料。実態どおりに書いてください
  safety: {
    install: { lv:"ok",   s:"インストール不要", d:"ブラウザで開くだけで使えます。" },
    login:   { lv:"ok",   s:"ログイン不要",     d:"アカウントは必要ありません。" },
    data:    { lv:"ok",   s:"外部送信なし",     d:"お手元のパソコンの中だけで処理されます。" }
  }
}
```

`lv` は3種類です。

| 値 | 表示 | 使いどころ |
|---|---|---|
| `ok` | 緑 | 安心材料になること |
| `note` | 灰 | 条件つき（ログインが要る、導入が要る など） |
| `warn` | 黄 | 注意が要ること（外部にデータが出る など） |

**ここに事実と違うことを書かないでください。** 一度でも齟齬が見つかると、サイト全体の信頼が失われます。

## 書き間違えたとき

GitHubから「ワークフローが失敗しました」というメールが届きます。
本文に、どの行のどこが問題か日本語で書かれています。

なお `tools.js` が壊れていても、サイトは白紙にはならず
「ツール情報を読み込めませんでした」と表示されます。

## `.github` の中身について

`.github` フォルダの中のファイルは、**GitHubのサーバー上でだけ動きます。**
ご自分のパソコンでダブルクリックしないでください。
（Windowsでは別の機能が起動してエラーになります。何も壊れませんが、意味がありません）

## ファイルの役割

| ファイル | 役割 | 編集 |
|---|---|---|
| `tools.js` | 掲載データ | **ここだけ編集** |
| `index.html` | 表示の仕組み | 見た目を変えるときだけ |
| `flyer.pdf` | A4紹介チラシ | 自動生成。手で触らない |
| `.github/scripts/make_flyer.py` | チラシの見た目 | チラシのデザイン変更時 |
| `.github/scripts/tools_to_json.cjs` | tools.js の確認 | 触らない |
| `.github/workflows/flyer.yml` | 自動化の設定 | ほぼ触らない |

## 移行時の注意

- `index.html` は差し替えになります。Search Console の認証タグ
  （`google-site-verification`）は新しい `index.html` にも入れてあります。
- `images/` フォルダはそのまま残してください。各ツールのサムネイルに使っています。
- Releases のダウンロードURLは変更していません。既存のリンクはそのまま有効です。
- 安全性バンドの文言は `tools.js` の `window.TRUST` にあります。
  **全ツールで例外なく真であることだけ**を書いてください。
