## カテゴリの追加

`CATEGORY_COLOR` に `"授業・行事の資料"` を1つ足してください。
既存の色と区別がつく色を選んでください。

## 確認していただきたいこと

README のスキーマに、カードから本体へ飛ぶURLのフィールドが載っていません。

- **`id` からパスを組み立てる規約の場合** — `id: "undokai-hyogen"` と
  フォルダ名 `undokai-hyogen/` が一致しているので、そのまま動きます。
- **`url` などのフィールドがある場合** — `url: "./undokai-hyogen/"` を足してください。

## チラシPDFについて

`tools.js` を変更すると `flyer.pdf` も自動で作り直されます。
A4に収まる長さかどうか、生成後のPDFを一度確認してください。
収まらない場合は `summary` を短くします（`description` ではなく `summary` が
チラシに載る想定であれば）。
